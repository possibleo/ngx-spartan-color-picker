# ngx-spartan-color-picker

Angular color picker for [Spartan NG](https://spartan.ng).

Requires Angular 19+ (21+ for Signal Forms), `@spartan-ng/brain`, and Tailwind v4 with a Spartan theme.

```bash
npm i ngx-spartan-color-picker
```

See the [repository README](https://github.com/possibleo/ngx-spartan-color-picker/blob/main/README.md) for usage and options.
